# Παραδοσιακός Σύλλογος «Σταυραετοί» — Χανιά Κρήτης

Επίσημη στατική ιστοσελίδα του Παραδοσιακού Χορευτικού Συλλόγου «Σταυραετοί» Χανίων (ίδρυση 1972)[cite: 1].

## Δομή Αρχείων
- `index.html` — Κύρια σελίδα (δίγλωσση: Ελληνικά / Αγγλικά), στυλ CSS και λειτουργικότητα JavaScript[cite: 1].
- `image1.png` — Λογότυπο Συλλόγου (επικεφαλίδα)[cite: 1].
- `image10.jpg` — Κεντρική φωτογραφία (Hero section)[cite: 1].
- `image2.jpg`, `image3.jpg`, `image4.jpg`, `image5.jpg`, `image7.jpg`, `image8.jpg`, `image12.jpg` — Φωτογραφίες γκαλερί[cite: 3].

## Προστασία Προσωπικών Δεδομένων (GDPR)
- Η ιστοσελίδα είναι στατική, δεν αποθηκεύει δεδομένα χρηστών σε βάση δεδομένων ούτε χρησιμοποιεί cookies παρακολούθησης[cite: 1].
- Τα στοιχεία που συμπληρώνονται στις φόρμες (εγγραφή σε τμήμα ή πρόσκληση σε εκδήλωση) προωθούνται μόνο τοπικά μέσω της εφαρμογής Email ή WhatsApp του χρήστη προς τα στοιχεία επικοινωνίας του Συλλόγου αποκλειστικά για την εξυπηρέτηση του αιτήματος[cite: 1].
- Για οποιοδήποτε αίτημα ενημέρωσης, διόρθωσης ή αφαίρεσης στοιχείων ή φωτογραφίας από το υλικό του Συλλόγου (σύμφωνα με τον Κανονισμό ΕΕ 2016/679 – GDPR), μπορεί να υποβληθεί αίτημα επικοινωνίας στο `stavraetoichania@gmail.com`[cite: 1].
